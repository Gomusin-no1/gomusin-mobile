# 고무신모바일 v3.0 실사용 테스트 버전

## 핵심 운영 원칙
- 직원: 본인 소속 지점의 판매일보 / 고객 / 고객서류 / 재고 / 페이백 / 고객약속 / 유선판매만 열람
- 관리자: 모든 지점 조회 + 지점 필터
- 화면에서 숨기는 수준이 아니라 서버에서도 지점 접근을 검사

## 고객약속 / 홈
- 오늘 약속을 상세 업무 목록으로 바로 표시
- 요금제 변경, 부가서비스 해지, 페이백을 홈에서 바로 완료 처리
- 기한초과 지속 표시
- 오늘 개통 숫자 클릭 → 오늘 판매일보
- 오늘 페이백 숫자 클릭 → 오늘 지급 목록

## 판매일보
- 직원은 본인 지점 판매일보만 조회
- 관리자는 전체/지점별 조회
- 날짜 필터
- 고객별 비공개 서류 보관
- PDF/JPG/PNG/WEBP, 파일당 최대 10MB
- 서류는 Render 로컬 디스크가 아니라 PostgreSQL에 저장하여 재배포 시에도 유지
- 고객/판매 지점 권한 확인 후에만 열람 가능

## 고객관리
- 고객명 클릭 → 고객 상세
- 최신순 개통이력: 개통일 / 단말기 / 통신사 / 개통유형 / 판매자 / 지점
- 미처리 고객약속 상단 요약
- 판매건별 약속 및 서류 연결

## 고객 문자 캠페인
- 관리자만 캠페인 생성·승인·일시정지 가능
- 개통월과 지점을 선택해 대상 고객 자동 추출
- 명시적으로 문자 수신에 동의한 고객만 예약하고 전화번호 중복 제거
- 설정한 일일 한도만큼 08:00~21:00에 발송
- 광고 표기·발신자·문의처·무료 수신거부 문구 자동 포함
- 발송 실패 시 15분 간격으로 최대 3회 자동 재시도
- 실행 API는 `CAMPAIGN_CRON_TOKEN` Bearer 인증 필수

필수 환경변수: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SMS_SENDER`, `SMS_SENDER_NAME`, `SMS_CONTACT`, `SMS_OPT_OUT_NUMBER`, `CAMPAIGN_CRON_TOKEN`

## 요금제
- SK / KT / LG 선택 후 현재 요금제와 변경 예정 요금제를 클릭 선택
- 관리자 `기준정보` 메뉴에서 요금제 추가/중지 가능
- 초기 데이터는 2026년 통신사 개편 정보를 참고한 기본 목록

## 재고
- 제조사 → 모델 검색 → 용량/색상 자동 후보
- 삼성/애플 최신 주요 모델 기본 등록
- 관리자 `기준정보`에서 모델 추가/중지 가능
- 직원은 자기 지점 재고만 열람
- 지점 간 재고 이동은 관리자만 가능

## 페이백
- 직원 본인 지점 / 관리자 전체 지점
- 오늘 처리예정 / 기한초과 / 전체 미지급 KPI 클릭
- 지급완료 시 고객약속과 동기화

## 유선판매 정산 v3
정산금 = 리베이트 + 구두추가 + 정산상품권 - 고객지급상품권 - 차감금액
세금 = 정산금 × 13.3%
최종마진 = 정산금 - 세금 - 페이백 + 상품권반납금액
